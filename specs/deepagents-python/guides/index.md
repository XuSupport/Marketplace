# Thinking Guides for Deep Agents

Use these guides before work that crosses package, public API, runtime, persistence, or permission boundaries.

- [Pre-implementation checklist](./pre-implementation-checklist.md): every non-trivial change.
- [Cross-layer thinking](./cross-layer-thinking-guide.md): behavior spanning SDK, middleware, persistence, interfaces, or deployment.

Always search before writing. Target source paths such as `libs/deepagents/deepagents`, `libs/deepagents/tests`, `libs/code`, or `libs/cli`; avoid broad searches that include virtual environments and generated metadata.
